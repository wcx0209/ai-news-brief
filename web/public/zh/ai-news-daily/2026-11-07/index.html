亚马逊 SageMaker 现已支持多实例 GPU，大幅降低AI推理成本

AWS Machine Learning人工智能商业原文发布时间2026-11-07 02:01 SGT
官方发布阶段未明确

据AWS Machine Learning发布的信息： 过去在云端部署AI模型时，大家常常面临两难：要么为小模型买单整张大显卡造成严重浪费，要么只能自己去搭建和维护复杂的 Kubernetes 集群。现在，亚马逊 SageMaker AI 直接内置了 GPU 分区功能，用户可以把 A100 或 H100 这样的高端显卡切成多块独立区域，并且由硬件层直接保证隔离性。 AWS 的实测表明，用较新显卡的一个分区去跑模型，性能和性价比甚至比整张旧显卡还要好。比如，一块切分后的 H100 片段在处理大并发任务时，速度更快且每百万token的成本更低。这项功能让企业能把各种大小模型混搭在同一台机器上，既不影响性能，又大幅提高了显卡利用率。

英伟达开源工具如何帮助研究人员打造下一代 6G 网络

NVIDIA Generative AI人工智能公司原文发布时间2026-11-07 00:00 SGT
官方发布阶段未明确
机器人与自主系统

据NVIDIA Generative AI发布的信息： 在过去的一年里，英伟达的 5G 和 6G 开源工具（如 Aerial 和 Sionna）下载量突破了百万大关，被全球 8000 多家研究和学术机构广泛使用。这些工具将仿真测试与人工智能训练同真实世界的无线实验连接起来，帮助研究人员攻克未来网络建设中的关键难题。 在伦敦国王学院，研究人员利用英伟达 Sionna 开发了面向机器人的目标导向语义通信技术。机器人不再传输完整的图像，而是只发送紧凑的物体描述，在动态环境中的任务完成时间缩短了最高 52.6%。与此同时，软银和苏黎世联邦理工学院的研究表明，人工智能神经接收机能够显著改善干扰环境下的信号接收和数据吞吐量。 能源管理和仿真速度也是主要的改进方向。利兹大学的研究人员利用英伟达技术预测网络需求，将基站能耗降低了 45.6%。此外，加泰罗尼亚电信技术中心利用图形处理器加速，将网络仿真运行时间从几小时缩短到十几分钟，从而加快了从创新构想到现实部署的进程。
