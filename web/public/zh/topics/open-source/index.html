thedotmack/claude-mem：为每个AI代理提供跨会话的持久化上下文

这是个什么项目？ 每次你开启一个新的AI编程会话时，AI助手总是从零开始。它会重新阅读相同的代码文件，问一样的问题，甚至踩进你们之前已经修复过的坑里。Claude-Mem 就像是给你的AI配了一个专属记事本，它静静地呆在旁边，记录下助手读过的每一行代码、做过的每一次修改和运行的每一条命令。 工作原理与核心功能 该项目通过本地的钩子（hooks）和轻量级服务来捕获活动。一个后台的观察者AI会把这些活动变成简短的观察记录，并在会话结束时生成摘要。当你开启新会话时，助手会先拿到一个精简的目录，只有在真正需要时才会去翻阅详细内容，从而大量节省Token。此外，它还提供了强大的搜索工具和网页端查看器，方便你随时回顾进度。 如何安装与使用 安装过程非常简单，只需要在终端中敲下一行命令。运行 npx claude-mem install 之后，安装程序会自动检测你电脑上装了哪些AI工具，配好插件并启动后台服务。如果你想了解更多高级配置或多语言模式，可以参考官方提供的详细文档。

NVIDIA/auto-ontology：用于构建语义图推理层的 Python 框架

详细功能 Auto Ontology 充当了原始数据库和 AI 智能体之间的桥梁。它通过自动读取数据库结构、分析字段并推导表与表之间的关系，为企业数据构建出一个语义知识图谱。开发者可以用它把大白话问题转换成精准的 SQL 查询，并借助英伟达 NIM 模型，确保每一个回答都附带可追溯的数据来源和执行步骤。 系统架构 该项目采用了现代化的微服务架构设计。它包含一个基于 Next.js 的前端网页界面、用于处理聊天和目录管理的 FastAPI Python 后端、负责向量嵌入的后台工作进程，以及搭配 pgvector 扩展的 PostgreSQL 数据库，用来存放应用数据和语义图谱。 安装与使用 使用 Docker Compose 可以非常轻松地跑起整个项目。你只需要克隆代码库，在 .env 文件中配好英伟达 API 密钥等环境变量，然后运行 Docker Compose 就能一键启动本地服务。启动后，你就可以连接自己的数据库，通过内置的聊天界面直接提问，或者通过 MCP 服务器将其无缝接入其他开发工具中。
