机器人行业正式迎来“后黄仁勋时代”

The Robot Report
原文发布 2026-11-20 11:06 SGT
媒体报道

英伟达董事会接受了黄仁勋的辞职，这让机器人行业失去了一位最具影响力的代言人和关键金主。虽然黄仁勋此前通过主题演讲、开发工具和战略投资大力推动了机器人技术的发展，但他离开后英伟达未来战略的不确定性，将对这个正处于快速成长期的新兴行业带来全新考验。

展开摘要

黄仁勋卸任英伟达CEO标志着机器人行业迎来了一个转折点。过去多年里，黄仁勋不仅在各大主题演讲中频繁为机器人摇旗呐喊，还通过真金白银的战略投资和技术支持，扶持了包括 Serve Robotics 在内的多家初创企业，构建了从芯片、仿真软件到基础模型的完整开发生态。

多位机器人行业高管表示，黄仁勋的持续关注极大地提升了整个行业的知名度与投资信心。然而，随着英伟达进入过渡期，加上核心数据中心业务面临的竞争与监管压力，英伟达未来是否会延续对机器人板块的大力投入和早期支持成为了未知数。

尽管业内人士普遍认为机器人行业的底层技术和生态已经具备一定的发展惯性，但随着人形机器人企业在未来一年内面临落实商业化落地的真实大考，失去这样一位重量级盟友和强音代言人，对整个行业而言无疑是一次重大的生态缺失。

麻省理工学院研发的微型飞行机器人，现在能自己背着传感器和电脑飞了

MIT Robotics
原文发布 2026-11-19 03:00 SGT
官方发布

据MIT Robotics发布的信息：麻省理工学院的研究人员设计出了一种扑翼微型机器人，能够自主携带传感器和计算设备。过去，这些超轻机器人由于无法负重，必须连接在实验室的动作捕捉系统上才能导航；而新版本不仅能飞行复杂的路线还能精准降落，这标志着微型机器人在精准农业应用中迈出了重要一步。

展开摘要

据MIT Robotics发布的信息：

背景与负载突破

在过去的十年里，麻省理工学院的研究人员开发出了像大黄蜂一样飞行的微型机器人，它们靠软体人工肌肉来扇动翅膀。然而，这些超轻机器人无法承载导航所需的电子设备，只能连着实验室的设备。为了解决这个问题，研究团队将人工肌肉的尺寸扩大了50%，使净升力提升了46%，实现了1.9的升重比，成功让机器人背上了重达244毫克的电子设备。

传感器与计算优化

如果没有实验室外部摄像头的辅助，机器人很容易偏离航向。为此，研究团队集成了一套包含惯性测量单元、光流传感器和飞行时间传感器的微型套件，并设计了高效的传感算法，通过牺牲一点绝对精度换取超快的计算速度，确保机器人不会迷失方向。在测试中，机器人的定位误差只有几厘米。

未来展望

尽管这个机器人目前仍然需要连接外部电源，但其搭载的电子设备只消耗了总电量的6%左右。研究团队目前正在努力攻关两个目标：加装摄像头来实现物体识别和避障，以及把电池和电源管理集成到机器人身上，从而实现真正的户外无线飞行。

Humyn Labs获4700万美元融资，为机器人提供真实世界训练数据

The Robot Report
原文发布 2026-11-19 06:43 SGT
媒体报道

物理人工智能初创公司 Humyn Labs 宣布完成总计 4700万美元 的A轮融资（含股权与债权）。该公司通过在 20多个国家 采集视觉、声音、触觉和运动等真实世界数据，帮助机器人企业解决从虚拟仿真走向实际落地的难题。

展开摘要

融资详情与营收增长

物理人工智能研究与部署公司 Humyn Labs 宣布完成 4700 万美元的 A 轮融资，其中包括由 Accel 领投的 2600 万美元股权融资，以及由 Lighthouse Canton 领投的 2100 万美元风险债融资。联合创始人 Ishank Gupta 表示，公司在运营短短六个月内，年度化营收已突破 5000 万美元。

四大模态的数据采集

Humyn Labs 致力于解决机器人行业的一大痛点，即如何将实验室的模拟环境转化为现实世界的实际应用。该公司利用自主研发的采集设备，在 20多个国家 收集视觉、声音、触觉和运动数据，其业务重点分布在拉丁美洲、南亚、东南亚和东亚。他们通过端到端的数据引擎，将人类的工作过程转化为符合研究人员需求的标注化、可直接用于训练的数据集。

资金用途与基础设施建设

这笔新资金将主要用于三个方面：在巴西、韩国和印度建立部署就绪的基础设施；升级其捕获硬件和数据增强引擎；以及扩大其在旧金山、伦敦和首尔的实地业务存在，从而让顶尖研究实验室免受繁琐的数据收集工作困扰。

工业无人机实地部署揭示的真实自主飞行挑战

The Robot Report
原文发布 2026-11-20 01:01 SGT
媒体报道

在工业场地上部署自主无人机，会暴露出实验室里很难遇到的真实挑战，比如导航、避障和飞控等子系统会产生意料之外的连锁反应。ZenaDrone 的撰稿人 Jonathan Metzelaar 指出，金属建筑、信号遮挡和阵风会同时干扰无人机，单一组件表现好不代表整体系统就安全。要实现可靠的工业自主飞行，工程师必须弄清楚误差是如何在整个系统里蔓延的，而不是只盯着单个零件的性能。

展开摘要

工业环境充满了各种复杂因素，对自主无人机的导航能力构成了严峻考验。金属建筑会阻挡或干扰卫星定位信号，而密集的管道和反光表面又会让视觉和激光雷达传感器分不清方向。此外，建筑物附近的阵风会产生复杂的空气动力干扰，给飞行控制器带来麻烦。

ZenaDrone 撰稿人 Jonathan Metzelaar 指出，无人机的自主飞行表现取决于各个子系统之间的相互影响，而这些子系统往往无法彼此独立。定位错误可能会导致避障坐标出现偏差，处理延迟也会直接转化为实际的刹车距离，这意味着评估避障系统不能只看探测距离，还得看整体的反应时间。此外，顺利飞完整条路线并不代表收集到的巡检数据（如热成像或摄影测量）就一定准确或可重复。

为了确保部署安全可靠，工程团队不能只在实验室里测试单个组件，必须在多种故障交织的场景下进行综合评估。这包括为定位、延迟和故障恢复制定可量化的验收标准，同时划定明确的操作边界并保留人类监督的介入机制。

软体机器人外骨骼帮老年人更轻松地站起来和走路

Robohub
原文发布 2026-11-19 18:09 SGT
媒体报道
人工智能

慕尼黑工业大学的研究人员开发了一款轻便的软体外骨骼服装，利用机器学习和人造肌腱来帮助老年人站立和行走。在一项针对十名老年参与者的研究中，这款服装帮助他们更快地完成起坐循环并减少了走路时的体力消耗，同时使用者依然觉得完全能自主控制自己的动作。

展开摘要

外骨骼是如何工作的

由慕尼黑工业大学研究人员开发的这款外骨骼穿起来就像一件衣服，配有大腿带、腰带以及连接在背包式电机单元上的人造肌腱。大腿上的传感器会实时追踪腿部动作，机器学习算法则会在用户站立或行走时精确触发电机拉动肌腱，提供髋部支撑。

研究结果与用户反馈

在涉及十名 69 岁至 85 岁老年人的测试中，这款服装显著改善了他们的行动能力。参与者在一分钟内多完成了最多四次起坐循环，且步行平均代谢消耗降低了 14%。据研究员 Xiaohui Zhang 称，用户还报告了极高的自主掌控感，感觉这套设备穿在身上就像普通衣服一样自然。
