在 AWS Trainium3 上运行 LTX-2.5 视频生成模型

Hugging Face
原文发布 2026-11-27 08:00 SGT
媒体报道

Hugging Face 研究人员在 AWS Trainium3 机器上测试了 LTX-2.5 视频与音频生成模型。通过使用张量与序列并行技术对代码流进行优化，他们成功在 22 到 23 秒内生成了一段 10 秒的高清视频，速度媲美商业 API。

展开摘要

Hugging Face 报道称，他们在一台 AWS Trainium3 机器（拥有 64 个 NeuronCore 的 trn3.48xlarge 实例）上进行了为期一个月的模型测试。在最后的几天里，他们部署了 Lightricks 的 LTX-2.5 模型来生成音视频同步的片段。最初，由于 Transformer 模型无法放入单个 NeuronCore，简单粗暴的运行方式导致每个视频片段耗时超过五分钟。

为了突破硬件限制，团队在 32 个 NeuronCore 上采用了张量并行与序列并行相结合的方案，并配合主机端的提示词缓存和共享内存解码等优化。最终的优化方案将 10 秒、2048x1024 分辨率视频的生成时间缩短至 22 到 23 秒，成功匹敌基于英伟达芯片的云端 API 速度。除了电影剧本草稿外，他们还将该模型作为世界模型，在真实的机器人和自动驾驶视频片段上进行了测试。
