官方发布

据AWS Machine Learning发布的信息：亚马逊云科技的 Bedrock 知识库现在能够自动记住用户的聊天历史和个人偏好。通过全新的 AgenticRetrieveStream 功能，开发者不用自己写数据库来存聊天记录，AI 就能自动把用户的上下文、长期记忆和文档权限结合起来，实现千人千面的智能问答，并且保证每个人的数据隐私和访问权限互不干扰。

展开摘要

据AWS Machine Learning发布的信息：

核心架构与背景

开发一个既能记住用户偏好、又能严格遵守公司文档权限的 AI 助手，过去需要写大量的数据库代码来管理聊天记录和用户身份。现在，亚马逊云科技将托管知识库与 AgentCore 记忆功能打通，把这些繁琐的后台工作交给了托管服务。

这种设计让企业无需再单独维护聊天记录表或复杂的权限控制逻辑。所有的记忆存储、隐私隔离和权限校验都由底层服务搞定，不仅大幅简化了开发流程，还从根本上保证了多用户共享知识库时的数据安全与隔离。
