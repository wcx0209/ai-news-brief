NVIDIA/auto-ontology：用于构建语义图推理层的 Python 框架

⭐ 11,039 | Auto Ontology 是英伟达开源的一个框架，专门为企业数据打造可靠的上下文层。它能解决 AI 智能体容易胡说八道或给出错误答案的痛点，通过自动梳理数据库里的表结构和业务含义，实现靠谱的可解释 AI 查询。

github.com ↗归档日期 2026-11-10新闻摘要人工智能

详细功能

Auto Ontology 充当了原始数据库和 AI 智能体之间的桥梁。它通过自动读取数据库结构、分析字段并推导表与表之间的关系，为企业数据构建出一个语义知识图谱。开发者可以用它把大白话问题转换成精准的 SQL 查询，并借助英伟达 NIM 模型，确保每一个回答都附带可追溯的数据来源和执行步骤。

系统架构

该项目采用了现代化的微服务架构设计。它包含一个基于 Next.js 的前端网页界面、用于处理聊天和目录管理的 FastAPI Python 后端、负责向量嵌入的后台工作进程，以及搭配 pgvector 扩展的 PostgreSQL 数据库，用来存放应用数据和语义图谱。

安装与使用

使用 Docker Compose 可以非常轻松地跑起整个项目。你只需要克隆代码库，在 .env 文件中配好英伟达 API 密钥等环境变量，然后运行 Docker Compose 就能一键启动本地服务。启动后，你就可以连接自己的数据库，通过内置的聊天界面直接提问，或者通过 MCP 服务器将其无缝接入其他开发工具中。
