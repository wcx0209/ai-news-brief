Ripple Preview v0.40.16：专为AI编程打造的65B大模型及Ollama更新

Ripple Preview 简介 Ripple Preview 是由 Ricursive Intelligence 开发的一个庞大的 65B 密度模型，专门为自动化编程任务而设计。你可以通过像 ollama run ripple-preview 这样的简单命令快速启动它，这对于希望将高级代码智能集成到本地工作流中的开发者来说非常方便。 主要更新与改进 这次发布在各个平台上带来了几项令人兴奋的升级。对于苹果芯片用户来说，Qwen3.8 Flash Next 现在可以少占用约 27 GiB 的内存，这让它在 Mac 硬件上运行变得更加容易。此外，ollama launch claude 现在可以稳定地将 Claude Code 路由到你选择的模型，并且 ollama launch 会在云端模型退役时给出提示。其他修复包括在 /v1/responses 中正确处理截断、在 /v1/models 中返回空列表而不是 null，以及为 ARM 架构的 Windows 增加了 CUDA 13.5 支持，同时升级了底层 llama.cpp。
