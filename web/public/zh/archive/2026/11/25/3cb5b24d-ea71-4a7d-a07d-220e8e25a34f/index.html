OS-Omni：跨平台多设备长周期工作流通用计算机操作代理基准测试

研究人员推出了 OS-Omni，这是一个涵盖 Windows、Ubuntu、macos、iOS、Android 和 Web 的实时跨平台基准测试与执行环境。评估显示前沿模型在 iOS 和 macOS 平台上仍落后于人类。

Hugging Face Daily Papers ↗原文发布时间 2026-11-25 03:00 SGT媒体报道人工智能

作者介绍了 OS-Omni，这是一个实时跨平台基准测试与执行环境，旨在评估计算机操作代理在 Windows、Ubuntu、macOS、iOS、Android 和 Web 环境中执行长周期工作流的能力。该基准测试的 v1 版本包含每个平台 48 个任务以及 12 个将桌面端与 Android 手机配对的跨平台工作流，并集成了带有持久状态的可控服务后端应用程序。人类基准研究表明，OS-Omni 任务平均需要 67.54 个交互步骤，大幅超过 OSWorld 等先前基准（15.0 个步骤）。v1 版本上的实验结果显示，评估中最强的代理 Claude Opus 5.5 平均成功率为 68.5%，落后于人类水平 8.8 个百分点。不同平台之间的表现差距显著：前沿模型在 Linux 上表现优于人类，但在 iOS 和 macOS 上落后人类超过 25 个百分点，这表明现有代理在异构操作系统间实现平台鲁棒性、持续状态跟踪和持久最终状态变更方面仍面临巨大挑战。
