Cloudflare 推出“Agent 搜索”功能，让 AI 轻松在网站里找资料

据Cloudflare AI发布的信息：Cloudflare 宣布推出名为 Agent 搜索的新功能，用户只需在后台点个开关，就能快速为网站建立 AI 搜索索引。据 Cloudflare 介绍，该工具会在网页中自动标注搜索接口，让各种 AI 助手不用费劲配置就能直接在网站里搜资料。

Cloudflare AI ↗原文发布时间 2026-11-25 22:00 SGT官方发布人工智能

据Cloudflare AI发布的信息：

Cloudflare 表示，以往想要给网站配个 AI 搜索，得手动搞一堆复杂的配置和集成工作。根据 Cloudflare 的说法，新推出的 Agent 搜索功能把这些繁琐步骤全部简化到了后台的一个开关里，系统会自动抓取网页内容并为 AI 助手开放标准的搜索接口。

Cloudflare 解释说，这个系统会在网页代码或 Markdown 头部自动标注搜索地址。当 AI 助手访问网站时，能一眼看出该去哪里用大白话或关键词搜资料，并且直接拿到整理好的 Markdown 格式原文，而不是靠另一个 AI 瞎猜着回答。

此外，Cloudflare 还提到，该功能原生支持了全新的 HTTP QUERY 方法（RFC 10008），允许通过请求体安全地发送查询。目前该服务已经向所有客户开放，并遵循现有的 AI Search 计费规则。
