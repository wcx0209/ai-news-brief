创业困境与 RSI 的生存空间 谷雨指出，大厂往往受困于创新者的窘境，这反而为像 NeoLab 这样的早期团队创造了切入和发展的机会。递归自我改进（RSI）与敏捷应对成为初创公司在巨头阴影下突围的关键。 基础模型迭代与认知打脸 在谈到技术前沿时，她提到一个残酷的行业现实：基础模型的突然升级（如 Opus 5.5）可能会让团队几个月的辛劳瞬间失效。同时，她坦言自己曾公开不看好 Memory Notes，但在实际进展面前被打脸，展现了技术快速演进下认知迭代的必要性。 学术生态松动与 Agent 的实用化 访谈还探讨了传统学术会议体系面临坍塌的趋势，以及 Personal Agent 在实际落地中展现出的真实效用，表明 AI 个人助理正在跨越实用性门槛。
