OpenAI 发布 GPT-6.2 Astra 与 Sol：性能更强且价格更便宜

据OpenAI News发布的信息：OpenAI 宣布推出用于复杂专业任务的 GPT-6.2 Astra 以及面向日常工作的 GPT-6.2 Sol。据 OpenAI 称，两款新模型在消耗更少词元的（token）同时能交付更好结果，其中 Astra 的 API 价格有所下降，而 Sol 维持原价。该公司表示，这两款模型在准备框架下均达到了网络安全和生物能力的最高安全标准阈值。

OpenAI News ↗原文发布时间 2026-11-18 01:45 SGT官方发布人工智能

据OpenAI News发布的信息：

OpenAI 宣布推出 GPT-6.2 Astra 和 GPT-6.2 Sol 两款新模型，旨在提升专业与日常工作流的效率和表现。据该公司称，GPT-6.2 Astra 为复杂的专业工作设定了新的质量标准，在 Agents' Last Exam 和 Terminal-Bench-Science 0.1 等基准测试中以更低的成本取得了更高分数。OpenAI 表示，Astra 的 API 输入和输出词元价格有所下降，缓存输入更是享有 60% 的折扣。

在日常应用方面，GPT-6.2 Sol 被定位为比 GPT-6.1 Sol 更聪明、更高效的替代方案，在代码编写和日常生活评估中表现出色，同时保持原有的 API 定价不变。两款模型均具备更强的计算机使用能力，可应用于 CAD、3D 设计和机械仿真等领域。

在安全方面，OpenAI 报告称两款模型在其准备框架下均达到了关键的网络安全阈值和高级生物能力阈值。因此，该公司正在实施更严格的安全防护和诸如 Daybreak 的专属访问计划，以管理相关的双重用途风险。
