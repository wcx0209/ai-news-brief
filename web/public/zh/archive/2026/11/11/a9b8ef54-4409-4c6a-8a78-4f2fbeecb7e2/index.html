面向 AI 代理设计：Resend 如何布局答案引擎优化与自主 API 交互

Latent Space人工智能访谈原文发布时间2026-11-11 03:57 SGT
访谈阶段未明确

代理自主选择 API 的兴起

随着编码代理变得越来越自主，它们越来越多地代表开发者做出基础设施决策——例如选择集成哪个邮件服务商。Zeno Rocha 探讨了诸如 Claude Code 之类的工具如何推荐特定服务，以及这些推荐在不同模型版本间如何变化。这一趋势催生了答案引擎优化（AEO），要求 API 提供商确保其文档、定价和功能能够轻松被非人类代理发现和解析。

为机器消费者进行设计

为了支持自主工作流，Resend 进行了实验，向代理提供 80 多个命名的模型上下文协议（MCP）工具，使它们能够读取 Markdown 格式的定价、独立注册服务并执行 API 调用。Rocha 详细阐述了这一范式的实际挑战，从处理 DNS 障碍和 Gmail 频率限制，到重新思考传统指标（如追踪像素），在通过软件代理进行交互时，这些传统指标可能不再能准确衡量人类的参与度。
