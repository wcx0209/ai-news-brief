在亚马逊云科技上运行 OpenAI Codex

OpenAI Codex 现在可以通过亚马逊云科技进行模型推理，让平台团队无需单独搭建一套访问系统，就能为开发者提供 AI 编程工具。企业可以根据控制需求，在原生 AWS 访问、AgentCore 网关或现有的大模型网关之间进行选择。 该方案将 Okta 等企业身份提供商与 AWS IAM 身份中心结合，确保开发者的每次请求都能被正确验证和追踪。在监控方面，团队可以使用 OpenTelemetry 收集指标并在 CloudWatch 仪表盘 上查看，同时通过严格的配置边界来保护敏感代码和数据安全。
