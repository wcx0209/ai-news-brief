GLM-5.3 现已上线 SambaCloud 并支持高速推理

据SambaNova发布的信息：Z.ai 的旗舰级智能体模型 GLM-5.3 现已登陆 SambaCloud，运行速度超过每秒 200 个 Token。该模型专为长时间的软件工程和多步骤任务打造，在 Terminal-Bench 3.0 等基准测试中取得了开源模型的顶尖成绩，且比多款闭源模型消耗更少的输出 Token。

SambaNova ↗原文发布时间 2026-11-12 02:16 SGT官方发布人工智能

据SambaNova发布的信息：

背景介绍

Z.ai 推出了其旗舰模型 GLM-5.3，专门用于处理复杂的软件工程和长时间的智能体工作流。该模型经过训练，能够独立应对真实代码库和企业系统中的多天工程任务，无需用户手动拆解每一个步骤。

关键细节

据 Z.ai 称，GLM-5.3 在 Terminal-Bench 3.0 上得分为 28.3，在 DeepSWE v1.1 上得分为 66.9，在开源模型中处于领先地位，同时保持了极高的 Token 效率。在内部测试中，它以每个任务约 5 万个输出 Token 达到了 31.4% 的准确率。此外，它还具备出色的防御性安全能力，在漏洞发现基准测试 CyberGym 上创下了最高公开得分。

行业影响

该模型目前已在 SambaCloud 上运行，速度超过每秒 200 个 Token，这有助于降低多轮智能体循环中的延迟。Claude Code 和 Strix 等主流智能体框架已经将大量流量导向该模型，将前沿的智能体能力与生产环境的速度需求结合在了一起。
