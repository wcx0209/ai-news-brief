anthropics/skills：Claude 智能体技能官方开源仓库

什么是智能体技能

技能本质上是包含指令、脚本和资源的独立文件夹，能够让 Claude 动态加载，从而大幅提升它处理专业任务时的表现。不管是按照公司的品牌规范写文档、分析特定的企业工作流，还是自动化个人日常任务，技能都能确保每次都做得又好又稳。 仓库内容与生产级实现

这个仓库展示了 AI 智能体的各种绝活，涵盖了创意设计、技术开发以及企业日常沟通等多个领域。最给力的是，它把支撑 Claude 强大文档处理能力的底层技能（包括 docx、pdf、pptx 和 xlsx 的编辑与生成）全开源了，全部采用 Apache 2.0 协议，供开发者直接参考。 如何使用与安装

开发者可以通过 Claude Code 轻松把这个仓库当作插件市场来用，直接运行几条简单的命令就能完成安装。同时，仓库里还提供了一个标准的模板结构，里面只有一个带 YAML 头部信息的 SKILL.md 文件，方便任何人从零开始 创建自定义技能。
