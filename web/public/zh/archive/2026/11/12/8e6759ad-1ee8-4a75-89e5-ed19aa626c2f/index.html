使用 Amazon Bedrock 和 Spring AI 构建自主 AI 智能体

AWS Machine Learning人工智能开源原文发布时间2026-11-12 09:18 SGT
官方发布阶段未明确

据AWS Machine Learning发布的信息：

在企业 Java 环境中构建自主 AI 智能体一直面临挑战，因为标准智能体框架无法直接解决扩展性、安全性和运维治理问题。据亚马逊称，Spring AI 与 Amazon Bedrock 及 AgentCore 平台的结合弥补了这一空白，使 Java 开发者能够使用依赖注入、自动配置和组合顾问等熟悉的开发习惯。 核心能力 该方案展示了人工智能如何超越简单的提示词响应交互，演变为具备规划、工具调用和记忆能力的智能体。架构介绍了两个主要系统：用于工具调用和记忆的单智能体旅游助手，以及多智能体智能文档处理平台。文档处理系统利用专业智能体、规则引擎和警报机制来安全地路由和处理文档。 生产基础设施 为了让智能体做好投产准备，Amazon Bedrock AgentCore 提供了托管运行时环境、会话记忆和身份管理。该系统融入了企业级安全、Micrometer 可观测性以及指数退避重试和熔断器等韧性模式，确保 Java 应用能够从原型平稳过渡到安全的生产部署。
