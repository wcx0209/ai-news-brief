亚马逊 AWS Quick AI 工作空间迎来多项更新，支持多智能体协作与网页端工作流

据AWS Machine Learning发布的信息：亚马逊近日宣布对其 AI 工作空间工具 AWS Quick 进行重大更新，主要带来自然语言构建工作流、支持后台运行的全新网页应用，以及多智能体协同功能。此次更新还接入了 Meta Ads 和 Amplitude 数据源，并增强了安全控制与多语言支持。

AWS Machine Learning ↗原文发布时间 2026-11-21 09:06 SGT官方发布人工智能

据AWS Machine Learning发布的信息：

亚马逊为其企业级 AI 工作空间 AWS Quick 推出了全面更新，旨在帮助团队将个人的日常工作流程标准化并提升协作效率。核心亮点包括通过对话构建业务流程，用户只需在聊天中描述任务，系统即可自动生成可编排智能体、工具和数据的确定性工作流。更新后的网页端应用提供了优化的主屏幕信息流、每日简报，以及允许用户关闭浏览器后任务仍在后台继续运行的功能。

此外，AWS Quick 现在支持多智能体协同，用户通过单个提示词就能同时唤醒多个专业智能体来处理复杂请求并整合结果。新推出的 Meta Ads 和 Amplitude 数据源连接器允许用户将营销与产品行为数据直接纳入查询中。在管理和安全方面，AWS Quick 增加了提示词安全防护网、基于用户组的权限控制以及数据源限制，并新增支持日语、德语、中英文及越南语。
