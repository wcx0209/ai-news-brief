LlamaIndex v0.14.26 发布：全面提升各集成组件的安全性和依赖更新

本次更新为 LlamaIndex 的众多集成包带来了重要的安全更新与依赖锁定。它通过重新锁定 Python 的 uv.lock 文件并提高最低 Python 版本要求来修复潜在漏洞，同时修复了核心包中 LangChain 桥接的弃用问题。

LlamaIndex Releases ↗原文发布时间 2026-11-14 06:38 SGT开源项目人工智能

v0.14.26 版本概述

LlamaIndex v0.14.26 版本主要关注系统维护、安全加固以及跨集成组件的一致性。它为大量的回调处理程序、嵌入提供商、图数据库和托管索引组件推送了更新。

核心安全与更新亮点

本次更新的一个重点是在各个集成的 uv.lock 文件中执行了Python 安全重锁，在不需要改变底层 Python 基线的情况下修复隐患。同时，为了安全修复，部分集成引入了破坏性变更以提高 requires-python 的要求。在 llama-index-core 核心包中，开发团队修复了一项导致 LangChain 桥接 导入失败的弃用问题。
