亚马逊与Anthropic推出全新API与企业级AI安全管控功能

据AWS Machine Learning发布的信息：亚马逊云科技宣布在 Amazon Bedrock 上正式推出信任访问程序 API，并开启 Anthropic 企业级前沿护栏和企业数据控制功能的公开预览。这些新工具让符合条件的机构在使用先进 AI 模型时，能够自主掌控模型安全审核与数据存储方式。

AWS Machine Learning ↗原文发布时间 2026-11-24 13:01 SGT官方发布人工智能

据AWS Machine Learning发布的信息：

亚马逊与 Anthropic 合作推出了全新功能，旨在帮助受监管行业安全使用前沿 AI 模型。新发布的信任访问程序 API 允许管理员通过单一界面和标准的 AWS 权限策略来发现、检查资格并加入安全与数据项目。随此 API 一同发布的还有企业级前沿护栏（EFS）和企业数据控制（EDC）的公开预览。

EFS 允许机构将保留的提示词和生成内容存储在他们自己的 Amazon S3 存储桶中，并使用专属的 AWS KMS 密钥进行加密。亚马逊和 Anthropic 均不保留数据副本，所有自动安全审核和标记的案例都由客户团队在内部处理。作为替代方案，EDC 提供了类似的自动安全监控，但使用亚马逊托管的存储和密钥。这些选项为医疗和金融等行业提供了严格的数据治理能力。
