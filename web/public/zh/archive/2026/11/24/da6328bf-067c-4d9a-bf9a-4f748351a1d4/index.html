CrewAI 1.15.45 版本发布：新增 PDF 导出与多项稳定性修复

CrewAI 发布了 1.15.45 版本，正式引入了将 HTML 或 Markdown 输出保存为 PDF 成果的新功能。本次更新带来了多项缺陷修复，包括依赖升级、凭证验证以及工具参数优化，旨在全面提升多智能体工作流的整体稳定性。

CrewAI Releases ↗原文发布时间 2026-11-24 11:54 SGT开源项目人工智能

新增功能与特性

根据发布说明，CrewAI 1.15.45 版本引入了将 HTML 或 Markdown 内容保存为 PDF 成果的新能力，进一步丰富了多智能体系统生成结果的导出和分享方式。

缺陷修复与稳定性提升

该版本包含了针对各个组件的大量缺陷修复。值得关注的修复包括通过升级 Python >=3.11 的 e2b 来解决依赖问题、拒绝空凭证并在服务器认证中使用恒定时间比较，以及针对目标架构验证外部模型。此外，更新还调整了 HyperbrowserLoadTool 的参数以使其在架构中可选，并进行了改进以防止缓存 save_artifact 工具结果。

文档更新

发布文档中特别说明了 anthropic 文件块不带有缓存控制，为集成特定大模型功能的开发人员提供了更清晰的技术指引。
