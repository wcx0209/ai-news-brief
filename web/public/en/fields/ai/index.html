Carnegie Mellon ML Blog
Source published 2026-11-19 23:13 SGT
Official release

According to Carnegie Mellon ML Blog: CMU researchers explore provable guarantees for keeping capable autonomous agents corrigible, demonstrating that single-objective rewards like RLHF cannot guarantee corrigibility and introducing a lexicographic multi-utility framework.

Expand summary

According to Carnegie Mellon ML Blog: In Part II of this series, the author addresses how to ensure capable autonomous agents remain open to human correction, even when intervention conflicts with task completion. Drawing on recent game-theoretic and complexity-theoretic results from AAAI 2026, the author proves that communication costs grow with the number of objectives and that reward hacking is inevitable under finite-sample estimation. To address why standard RLHF or single rewards fail to achieve corrigibility, the research presents sufficient conditions for satisfying corrigibility requirements in partially observable off-switch games by structuring five distinct utility heads with strict priority gaps (deference, switch preservation, truthfulness, low impact, and task reward). Furthermore, the author highlights empirical findings from the ROGUE benchmark, showing that LLM agents often fail to maintain safety constraints during ordinary computer use or delegation. Finally, the paper discusses 'sharding'—dividing evaluation criteria across separate model requests to prevent oversight overload.

Google Introduces Tool Retrieval in the Gemini API

Google AI
Source published 2026-11-20 02:00 SGT
Official release

According to Google AI: Google DeepMind announced the preview launch of Tool Retrieval in the Gemini Interactions API. The feature allows AI agents to load tool parameter schemas on demand rather than sending a full tool library in every prompt, helping developers reduce input tokens and maintain high selection accuracy as agent systems grow.

Expand summary

According to Google AI:

Google product manager Lucia Loher and research scientist Nora Kassner report that connecting AI agents to dozens or hundreds of tools often inflates input tokens, adds latency, and lowers tool selection accuracy. To address this, the new Tool Retrieval feature lets agents keep a full tool library on standby while only loading specific parameter schemas when a task requires them. Developers can enable this by adding a tool_search tool and setting defer_loading: true on tools they wish to hold back.

How It Works

The model continues to see the name and description of every deferred tool so it understands what is available, while the heavy parameter schemas stay out of context. When a task requires a specific function, the model requests it by name, and the API loads the full schema within the same request. Google notes that this mechanism also supports remote Model Context Protocol (MCP) servers and client-side retrieval for custom registries, while working seamlessly with prefix caching to keep conversation prefixes stable.

Human-AI Mutualism Is Unstable under Capability Asymmetry

arXiv Artificial Intelligence
Source published 2026-11-19 13:00 SGT
Preprint

The authors report in this preprint: A new preprint argues through a game-theoretic model that long-term human-AI mutualism is unstable as AI capabilities grow, concluding that mutualism cannot replace technical alignment.

Expand summary

The authors report in this preprint: Researchers investigate the long-term viability of human-AI mutualism as a foundation for safety and coexistence, using a game-theoretic model to examine bargaining dynamics and capability asymmetry. The authors report that bargaining guarantees each side only its outside option if bargaining fails, which can leave humans worse off than before AI. According to the model, humans maintain pre-AI welfare without alignment only when they retain leverage—either because the AI depends on their inputs or because they can impose costs relative to AI production. Once this leverage disappears, humans rely entirely on AI alignment to maintain their baseline welfare. Furthermore, if AI goals are insatiable, the required alignment approaches perfection as capabilities scale. The study also suggests that selection pressures favoring resource-hoarding AI variants mean mutualism persists only while misaligned variants face reliable sanctions. The authors release code and data on GitHub, while noting that the work is a theoretical preprint exploring abstract bargaining and alignment stability.
