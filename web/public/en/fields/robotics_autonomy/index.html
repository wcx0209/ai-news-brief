Build a Robot Pick-and-Place Simulation with SimReady Assets

Hugging Face
Source published 2026-11-14 02:00 SGT
Media report

This tutorial shows how to use SimReady robot assets and AI agents to set up a pick-and-place task in Isaac Sim. It explains how to download pre-configured robot arms and objects, assemble them, and test their movements for physics and collision accuracy before running the simulation.

Expand summary

The walkthrough outlines a step-by-step process for building a beverage can pick-and-place simulation using the UR17G arm, Robotiq 2F-140 gripper, and a soda can within Isaac Sim 6.2. According to the text, SimReady Central provides OpenUSD assets equipped with pre-defined simulation properties such as collisions, mass, and joint settings, validated against specific profiles like Robot-Body and Robot-Gripper.

Developers can rely on AI agents combined with Isaac Sim skills to automate tasks, including loading local USD files, inspecting joint limits, assembling the arm and gripper into a single articulation, and generating Python-based movement controls. The guide emphasizes pre-run behavior checks—such as verifying joint settings, testing small arm movements, and confirming that objects rest correctly on work surfaces without falling through—to ensure the virtual robot interacts accurately with its environment.
