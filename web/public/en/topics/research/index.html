Google DeepMind uses AI to mathematically prove Signal protocol security

How It Works Google DeepMind researchers built AlphaProof Code, a multi-LLM framework that combines human expertise with AI agents. Human experts worked with models to translate Signal's security goals into formal mathematical specifications, while Gemini Carbon-powered agents generated over six million lines of Lean, a computer language used for mathematical proofs. Why It Matters Most security verification stops at the design level, but this system proved that the compiled code actually fulfills its security promises down to the exact code running on user devices. This bridges a major gap where real-world vulnerabilities often hide, cutting down verification time drastically. Future Impact This breakthrough demonstrates how AI can bring elite security assurance to critical systems like medical device firmware and power grids, helping defend against modern cyber threats while safeguarding billions of private conversations.

Google Research introduces AI system to detect hypertension using smartwatches

Background High blood pressure is a widespread health issue that often goes unnoticed because it rarely shows obvious symptoms. Traditional wearable blood pressure trackers usually require regular arm cuff calibration to measure relative changes, which limits their usefulness as independent screening tools. Technology Google Research scientists created a multimodal AI system named AI-PPG-ACC-HTN. It analyzes sensor data from consumer smartwatches over multiple days, using a deep convolutional neural network trained through self-supervised contrastive learning. By combining these passive physiological signatures with the user's height, the system calculates a continuous hypertension probability score. Impact Validated against 24-hour ambulatory blood pressure monitoring in a clinical study, the smartwatch system showed high specificity and predictive value. While not meant to replace standard medical devices, this technology could offer a scalable screening tool to catch the condition early and encourage people to seek professional medical care.

Apple Researchers Train Neural Networks to Speed Up RAG Retrieval

In a paper presented at ICML 2026, Apple researchers introduced a technique called amortized maximum inner product search (MIPS) to improve retrieval-augmented generation (RAG) and search systems. Traditional systems often rely on geometric approximations, such as clustering keys and comparing queries to cluster centroids, which can lead to errors because queries (short user questions) and keys (long curated texts) differ significantly. To solve this, the researchers train small neural networks offline—specifically SupportNet and KeyNet—using supervised learning on typical query distributions. SupportNet learns the mathematical support function of data clusters to route queries more accurately, helping the system find the right partition up to 1.9 times faster than traditional centroid routing. Meanwhile, KeyNet acts as a query rewriter that transforms incoming questions directly into predicted key vectors, allowing existing index systems to retrieve true keys up to 11 times fewer database scans. This method effectively trades a one-time training cost for significantly faster inference, demonstrating how knowing the query distribution in advance can dramatically optimize computational resources in production machine learning systems.

Harness-S: Training Smarter AI Agents Using Sibling Execution Systems

Background Training AI agents to handle complex coding and tool-use tasks usually relies on a fixed execution harness. However, every tweak to these scaffolds tends to fix some errors while breaking others, making it hard to find a universally superior setup. Details To solve this, researchers developed Harness-S. It builds a pool of specialized sibling harnesses along different repair directions. When the primary base harness fails completely on a task, the system routes the problem to these auxiliary harnesses to generate successful trajectories. An Adaptive Harness Router uses behavior profiles and LLM voting to select the best helper harness. The agent then learns from these rescued runs, effectively absorbing the helper behaviors into its own core policy. Impact Experiments across benchmarks like AppWorld, SWE-Gym, and DBBench show that the resulting policy greatly outperforms standard reinforcement learning methods when returning to the original base system. This proves that diverse execution environments can successfully transfer useful skills directly into the AI model itself.
