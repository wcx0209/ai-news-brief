How LlamaParse Pen Tested Against OWASP LLM Risks

Background and Testing Approach Traditional security tests are great for standard web apps, but they fall short when dealing with AI models that read customer documents. To ensure rigorous security, LlamaParse hired a dynamic application security testing firm using AI agents. These agents spent four days autonomously reading documentation, writing code, generating sample files, and attacking the production environment across all ten OWASP LLM risk categories. Key Findings and Lessons Among the findings was a subtle attack where invisible white-on-white text inside a PDF invoice altered extracted bank account details. This raised a crucial question about responsibility: should the parsing tool filter out such anomalies, or should the customer's downstream pipeline handle trust decisions? LlamaParse concluded that extraction should faithfully report what is on the page, while customers must implement business validation rules. Enterprise Security Controls Beyond the pen test, LlamaParse outlines robust enterprise controls, including strict data privacy policies that prevent customer data from being used for model training, SOC 2 compliance, and flexible deployment options ranging from managed SaaS to self-hosted environments.

Amazon Bedrock brings DeepEval and AutoEval to AgentCore for better AI agent testing

The Evaluation Challenge When deploying AI agents to production, simple metrics like latency or basic output checks aren't enough. An agent might resolve a customer support ticket while simultaneously leaking sensitive personal data. To fix this, Amazon Bedrock AgentCore Evaluations provides a structured way to measure what truly matters by mapping business goals to observable behaviors. Developers can also create custom dimensions to grade multiple criteria in a single judge call. Flexible Running Modes To fit different development stages, AgentCore supports three execution modes using the exact same evaluator IDs. On-demand evaluation helps during quick debugging, online evaluation samples live production traffic, and batch evaluation runs regression tests against a golden dataset before any new release.

Voyager 1 Reaches One Light-Day Distance From Earth

Launched in 1977, Voyager 1 is officially humanity's most distant space traveler. It has traveled so far that a signal from Earth now takes a full 24 hours to reach the spacecraft. Originally designed to explore the outer planets during a rare planetary alignment, the probe eventually entered interstellar space in 2012, continuing to send back valuable scientific data from beyond the sun's protective bubble.
