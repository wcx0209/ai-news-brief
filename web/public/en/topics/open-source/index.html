thedotmack/claude-mem: Persistent Context Across Sessions for Every Agent

What is Claude-Mem? Every time you start a new coding session with an AI agent, it starts from absolute zero. It re-reads the same files, asks the same questions, and falls back into mistakes you've already fixed together. Claude-Mem acts as a durable memory layer that sits beside your agent, silently taking notes on every read, edit, and command execution. How It Works and Core Features The system runs a local worker service powered by hooks. A secondary AI observer turns activity streams into concise observations and summarizes them when a session wraps up. When you open a new session, your agent receives a compact index of past work, fetching full details only when necessary. This saves tokens and keeps context sharp. It also provides advanced MCP search tools and a local web viewer for tracking your progress. Installation and Getting Started Getting started takes just a single command in your terminal. By running npx claude-mem install, the tool automatically discovers the supported AI agents on your machine, configures the necessary plugins, and starts the background worker. Detailed guides, custom modes, and configuration options are fully documented in the official repository.

NVIDIA/auto-ontology: A Python framework for building semantic, graph-based reasoning layers

Detailed Features Auto Ontology acts as a bridge between your raw databases and AI agents. It automatically ingests database schemas, profiles columns, and infers table relationships to build a semantic graph of your enterprise data. Developers can use it to translate natural language questions into accurate SQL queries powered by NVIDIA NIM, ensuring that every answer comes with verifiable provenance and execution steps. System Architecture The project is designed with a modern microservices architecture. It includes a Next.js frontend for the Web UI, a FastAPI Python backend for chat and catalog management, an ingestion worker for vector embeddings, and a PostgreSQL database equipped with pgvector to store both application data and the semantic ontology. Installation and Usage Getting started is straightforward using Docker Compose. You simply need to clone the repository, configure your environment variables including your NVIDIA API key in a .env file, and run Docker Compose to spin up the local stack. Once running, you can connect your databases and start asking questions through the built-in chat interface or integrate it with other tools via the MCP server.
