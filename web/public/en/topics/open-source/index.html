GitHub TrendingOpen Source09:27 SGTImportance 85

vercel-labs/agent-desktop: Computer use CLI for AI agents

Overview agent-desktop is a command-line interface and C library designed to give AI agents native computer-use capabilities. Instead of relying on brittle screenshots or pixel-matching techniques, it leverages official OS accessibility APIs to read desktop applications directly, presenting them as structured JSON trees. How It Works The tool inspects the target application and assigns a unique reference (ref) to every interactive UI element. The calling agent queries a snapshot, performs actions like clicking or typing using the ref, and checks the updated UI state in a continuous loop. By default, it operates headless, interacting with UI elements without needing to move the mouse pointer or steal active focus. Ecosystem and Integration agent-desktop natively supports macOS, Windows, and Linux by wrapping platform-specific accessibility APIs like AX API, UI Automation, and AT-SPI. It also includes an MCP (Model Context Protocol) server mode out of the box, allowing developers to easily expose all desktop commands as tools to any compatible AI assistant.

GitHub TrendingOpen Source09:27 SGTImportance 88

NVIDIA/auto-ontology: A Python framework for building semantic, graph-based reasoning layers

Detailed Features Auto Ontology acts as a bridge between your raw databases and AI agents. It automatically ingests database schemas, profiles columns, and infers table relationships to build a semantic graph of your enterprise data. Developers can use it to translate natural language questions into accurate SQL queries powered by NVIDIA NIM, ensuring that every answer comes with verifiable provenance and execution steps. System Architecture The project is designed with a modern microservices architecture. It includes a Next.js frontend for the Web UI, a FastAPI Python backend for chat and catalog management, an ingestion worker for vector embeddings, and a PostgreSQL database equipped with pgvector to store both application data and the semantic ontology. Installation and Usage Getting started is straightforward using Docker Compose. You simply need to clone the repository, configure your environment variables including your NVIDIA API key in a .env file, and run Docker Compose to spin up the local stack. Once running, you can connect your databases and start asking questions through the built-in chat interface or integrate it with other tools via the MCP server.

Hugging FaceOpen Source23:05 SGTImportance 77

NVIDIA and Elith Release Million-Scale Synthetic Financial Persona Dataset for Japan

Background In the financial sector, developing agentic AI is heavily constrained by strict privacy laws, compliance rules, and a lack of open, realistic data. To solve this, Elith and NVIDIA teamed up to create Nemotron-Personas-Finance-Japan, expanding on the earlier Nemotron-Personas-Japan collection with a specific focus on household finance and financial literacy. Dataset Details The dataset was built using NVIDIA's NeMo Data Designer and official Japanese statistics, featuring 9 million total personas across 50 detailed fields. It incorporates feedback from major Japanese financial institutions like Mizuho and Sompo Japan to ensure cultural authenticity and practical utility. Every record is entirely synthetic, meaning no real individuals' privacy is compromised. Industry Impact Released under a commercial-friendly CC BY 4.0 license, the dataset helps Japanese developers create localized AI agents, test for bias, and simulate customer interactions without using actual customer records. It paves the way for secure, sovereign AI development in the financial industry.

GitHub TrendingOpen Source08:56 SGTImportance 90

thedotmack/claude-mem: Persistent Context Across Sessions for Every Agent

What is Claude-Mem? Every time you start a new coding session with an AI agent, it starts from absolute zero. It re-reads the same files, asks the same questions, and falls back into mistakes you've already fixed together. Claude-Mem acts as a durable memory layer that sits beside your agent, silently taking notes on every read, edit, and command execution. How It Works and Core Features The system runs a local worker service powered by hooks. A secondary AI observer turns activity streams into concise observations and summarizes them when a session wraps up. When you open a new session, your agent receives a compact index of past work, fetching full details only when necessary. This saves tokens and keeps context sharp. It also provides advanced MCP search tools and a local web viewer for tracking your progress. Installation and Getting Started Getting started takes just a single command in your terminal. By running npx claude-mem install, the tool automatically discovers the supported AI agents on your machine, configures the necessary plugins, and starts the background worker. Detailed guides, custom modes, and configuration options are fully documented in the official repository.

Reflection AIOpen Source08:00 SGTImportance 86

Reflection releases Beam, an open-weight AI model with advanced safety features

Training and Alignment Reflection developed Beam by combining pretraining data filtering with a dedicated safety post-training pipeline. The company trained two distinct teachers, one for capability and another for safety and alignment, subsequently merging them through multi-teacher on-policy distillation. By increasing the parameter scale of the safety teacher from 100B to 501B, Reflection reduced over-refusal rates significantly while maintaining low harmful-request pass rates, demonstrating that model capacity aids in distinguishing permissible requests from harmful ones. Evaluations and Systemic Risks To assess potential harms, Reflection created Iris Safety Evaluations (ISE) and the Open Safety Framework (OSF). Beam demonstrated strong refusal performance across various sensitive categories, including cyber offense and biological risks. Independent testing by specialized organizations rated Beam as Limited across major systemic risk categories, confirming that its release does not expand the broader threat landscape compared to existing open models.
