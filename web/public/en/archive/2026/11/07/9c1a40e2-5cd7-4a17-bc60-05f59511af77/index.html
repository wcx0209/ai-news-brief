v0.66.0 - New AI models added with breaking export command changes

Qualcomm AI Hub ReleasesArtificial IntelligenceOpen SourceSource published2026-11-07 00:22 SGT
Open sourceStage not established

New AI Models This release welcomes several powerful new models to the platform. You can now access AG-Pose for pose estimation, netvlad for place recognition, Parakeet TDT for speech tasks, and LFM3 (including its vision variant) running on GGUF via GenieX llama.cpp. Breaking Changes & Improvements There are important updates to how you interact with the system. The old deprecation warnings for python export commands are gone, and running them directly will now throw an error; you must switch to using the new qai-hub-models export command instead. On the bright side, we now have phi_4_mini_instruct onboarding, better w8a16 quantization support replacing w8a8 for minilm_v2, and updated Qwen3 assets. Under the Hood For developers and system builders, configuration files like perf.yaml can now be easily parsed using standard protobuf libraries thanks to newly added proto definitions. SDK dependencies have also been refreshed, bumping PyTorch to version 2.14.1 and ONNX max compatibility to 1.22.0.
