OpenAI Codex on Amazon Bedrock

OpenAI Codex can now use Amazon Bedrock for inference, allowing platform teams to provide developers with AI coding tools without managing a separate access stack. Organizations can choose from Native AWS Access, Amazon Bedrock AgentCore Gateway, or an existing Large Language Model Gateway based on their control requirements. The setup integrates corporate identity providers like Okta with AWS IAM Identity Center, ensuring that developer requests are properly authenticated and attributed. For monitoring, teams can deploy the AWS Distro for OpenTelemetry to track metrics on Amazon CloudWatch dashboards while keeping sensitive code and data protected through strict configuration boundaries.
