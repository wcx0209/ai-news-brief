How OpenAI uses autonomous agents to keep ChatGPT fast

According to OpenAI News: OpenAI reports building an autonomous system called the Performance Factory to automate fixing performance slowdowns in ChatGPT. Powered by Codex and cloud agents, the system handles investigations and proposes code fixes, tracking over 1,700 investigations and root-causing more than 600 cases in three months.

OpenAI News ↗Source published 2026-11-19 16:00 SGTOfficial releaseArtificial Intelligence

According to OpenAI News:

OpenAI describes the evolution of its performance engineering from manual investigations to an automated agent factory. The Performance Factory consists of four main components: a task service with configurable workflows, a dispatch loop, cloud-based execution, and event subscriptions.

Its first deployed workflow, the Regression Workflow, takes over when a performance alert fires. An agent investigates metrics and logs, undergoes an adversarial review by a separate AI session to check for errors, and proposes a pull request for engineers to review. After deployment, another agent verifies whether performance has recovered to baseline. OpenAI notes that while finding root causes has seen high accuracy, writing the correct code fix remains harder and often requires human architectural guidance.
