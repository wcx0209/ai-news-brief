CrewAI v1.15.42: Optional ChromaDB and Qdrant Defaults

CrewAI released version 1.15.42, a popular framework for orchestrating AI agents. This update makes ChromaDB an optional dependency and defaults knowledge storage to local Qdrant. It also delivers multiple bug fixes for tool selection, JSON data handling, and security vulnerability patching.

CrewAI Releases ↗Source published 2026-11-19 00:38 SGTOpen sourceArtificial Intelligence

Overview of New Features

CrewAI has rolled out version 1.15.42, bringing significant adjustments to its storage architecture and agent capabilities. A major highlight is making ChromaDB an optional extra, allowing developers to leaner installations. Additionally, the framework now defaults knowledge storage to local Qdrant, decoupling storage dependencies and streamlining local vector search configurations. Bug Fixes and Enhancements

The release addresses numerous operational stability issues. It includes fixes for storing output_json values properly as JSON to prevent date formatting bugs, ensuring each Flow receives a distinct ID, and honoring max execution time limits accurately. Furthermore, it introduces security updates such as raising the soupsieve floor to version 4.0 to mitigate CVE-2026-126190, and guarantees robust UTF-8 file reading across project helpers and environment files.

Installation and Usage

Developers can update or install the latest version via Python's package management tools. For projects leveraging vector databases or complex agentic workflows, reviewing the updated ChromaDB and Qdrant configurations is recommended to ensure smooth execution.
