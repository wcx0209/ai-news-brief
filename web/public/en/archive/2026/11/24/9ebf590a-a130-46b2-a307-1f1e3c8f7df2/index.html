Amazon and Anthropic Launch New API and Controls for Enterprise AI Safety

According to AWS Machine Learning: Amazon Web Services announces the general availability of the Trusted Access Program API on Amazon Bedrock, alongside a public preview of Anthropic's Enterprise Frontier Safeguards and Enterprise Data Controls.

AWS Machine Learning ↗Source published 2026-11-24 13:01 SGTOfficial releaseArtificial Intelligence

According to AWS Machine Learning:

Amazon and Anthropic have partnered to introduce new features designed to help regulated industries use frontier AI models securely. The newly released Trusted Access Program API allows administrators to discover, check eligibility, and enroll in safety and data programs through a single interface using standard AWS IAM policies. Alongside this API, the companies launched public previews for Enterprise Frontier Safeguards (EFS) and Enterprise Data Controls (EDC).

EFS allows organizations to store retained prompt and completion data inside their own Amazon S3 buckets, encrypted with their own AWS KMS keys. Neither Amazon nor Anthropic retains copies of the data, and all automated safety reviews and flagged cases are managed internally by the customer's team. Alternatively, EDC provides similar automated safety monitoring while utilizing Amazon-managed storage and keys. These options offer strict data governance for sectors such as healthcare and financial services.
