AWS Quick updates bring multi-agent workflows and web app upgrades

According to AWS Machine Learning: AWS announces major updates to Quick, its workplace AI tool, featuring natural language flow building, a redesigned web app with background task execution, and multi-agent orchestration. The release also adds Meta Ads and Amplitude connectors, improved security controls, and support for additional languages.

AWS Machine Learning ↗Source published 2026-11-21 09:06 SGTOfficial releaseArtificial Intelligence

According to AWS Machine Learning:

AWS has rolled out a comprehensive update to its enterprise AI workspace, AWS Quick, designed to help teams operationalize individual workflows and collaborate more efficiently. Key features include conversational process building, where users can describe business tasks in chat to automatically generate deterministic flows that orchestrate agents, tools, and data. The updated web app features a prioritized home screen feed, a daily briefing, and background task processing that lets users close the browser while agents continue working.

Additionally, AWS Quick now supports multi-agent orchestration, enabling a single prompt to summon several specialized agents simultaneously to handle complex requests and combine their findings. New enterprise data connectors for Meta Ads and Amplitude allow users to pull marketing and product behavioral data into their queries. Administrative controls have also been expanded with prompt guardrails, group-level permissions, and data source restrictions, alongside new language support for Japanese, German, Chinese, and Vietnamese.
