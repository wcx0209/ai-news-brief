Amazon SageMaker HyperPod adds managed cluster extensions for Slurm

According to AWS Machine Learning: Amazon announced cluster extensions for SageMaker HyperPod Slurm clusters, introducing managed software packages that simplify observability and user management. Instead of relying on manual lifecycle scripts, administrators can now declaratively manage software configurations through APIs or the console to keep nodes consistent and healthy.

AWS Machine Learning ↗Source published 2026-11-21 07:07 SGTOfficial releaseArtificial Intelligence

According to AWS Machine Learning: Maintaining a shared Slurm cluster for foundation model development has traditionally required synchronizing multiple configuration files, custom scripts, and user rosters across nodes. To address configuration drift, Amazon SageMaker HyperPod has expanded its declarative management approach to running nodes. The newly launched cluster extensions currently support two main capabilities: an observability extension that collects metrics for CloudWatch or Prometheus, and a user management extension that handles local accounts, Active Directory integration, SSH access, and Slurm accounting. These extensions are validated up front against schemas, applied consistently to all nodes including newly scaled or replaced instances, and provide detailed health monitoring without requiring fleet-wide script updates.
