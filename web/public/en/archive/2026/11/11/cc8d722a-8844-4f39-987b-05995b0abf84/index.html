What's New in v1.4.10

The latest version of LangChain, v1.4.10, brings a few under-the-hood fixes and security updates to make building AI applications more reliable. This release is a minor patch focusing on code cleanup and fixing specific edge cases. Key Fixes and Improvements

One of the main highlights is a bug fix that keeps middleware-internal model calls completely off the regular message stream, preventing unwanted noise in your data. Additionally, it addresses python dependency security issues through patched locks and ensures trace inputs are properly omitted from the ModelRefusalMiddleware.
