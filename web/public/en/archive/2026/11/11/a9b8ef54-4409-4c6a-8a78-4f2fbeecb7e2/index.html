Designing for AI Agents: How Resend is Optimizing for Answer Engines and Autonomous APIs

The Rise of Agentic API Selection As coding agents become more autonomous, they increasingly make infrastructure decisions on behalf of developers—such as choosing which email provider to integrate. Zeno Rocha explores how tools like Claude Code recommend specific services and how these recommendations shift across model versions. This trend introduces answer engine optimization (AEO), requiring API providers to ensure their documentation, pricing, and capabilities are easily discoverable and parsable by non-human actors. Designing for Machine Consumers To support autonomous workflows, Resend has experimented with giving agents over 80 named Model Context Protocol (MCP) tools, enabling them to read pricing written in Markdown, register for services independently, and execute API calls. Rocha details the practical challenges of this paradigm, from handling DNS hurdles and Gmail throttling to rethinking traditional metrics like tracking pixels, which may no longer accurately measure human engagement when interacting through software agents.
