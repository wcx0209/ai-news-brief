v0.40.17 - Performance Boosts and Smarter AI Tooling Updates

What's New in This Release This version focuses heavily on making local AI run faster and more reliably across different hardware. For starters, the Apple Silicon MLX backend now supports concurrent generation, meaning you can juggle multiple AI tasks at once without lag. Hardware and Memory Upgrades If you are running AI on integrated graphics using Vulkan, the system now uses mmap for Vulkan, which significantly improves memory efficiency. Plus, the core engine has been bumped to a newer version to keep things stable and up-to-date. Better Command Line Experience For people who love using the command-line interface, this update improves the ChatGPT CLI with graceful restart features. This means if something hiccups, it recovers gracefully instead of losing your workflow.
