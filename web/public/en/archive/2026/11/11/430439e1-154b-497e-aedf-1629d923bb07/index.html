Ollama v0.40.17 - Performance Boosts for Vulkan and Apple Silicon

What's New in This Release This update focuses heavily on fixing bugs and boosting performance across different hardware setups. If you've ever experienced frustrating interruptions while using the command-line tool, you'll be glad to know that the ChatGPT CLI restore and graceful restart features have been significantly improved. Hardware and Performance Optimizations For users running AI models on integrated graphics, the team has introduced a clever memory-mapping technique using mmap specifically for Vulkan integrated GPUs. Additionally, Apple Silicon users will benefit from new concurrent generation support through MLX, making local AI tasks much faster and more responsive.
