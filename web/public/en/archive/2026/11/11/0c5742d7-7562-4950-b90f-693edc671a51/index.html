Baidu Unveils Ernie 5.5 Flash Preview, Mastering End-to-End Coding for Games and 3D

Key Features The new Ernie 5.5 Flash Preview boasts 280-billion total parameters, activating only 14-billion per inference, while supporting a 1-million token context window and generating over 200 tokens per second. Practical Capabilities Unlike traditional AI assistants that require human supervision for debugging, this model uses execution trajectories and automated loops. It runs code in real environments, inspects visual or logical errors, and fixes them iteratively, successfully generating a playable browser game and a full Blender garden from scratch. Ecosystem Impact Baidu announced that the model weights will soon be open-sourced under the Apache 2.0 license, alongside discounted API pricing on the Qianfan platform, lowering the barrier for developers to build complex applications.
