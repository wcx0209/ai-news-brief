NVIDIA/auto-ontology: A Python framework for building semantic, graph-based reasoning layers

Detailed Features Auto Ontology acts as a bridge between your raw databases and AI agents. It automatically ingests database schemas, profiles columns, and infers table relationships to build a semantic graph of your enterprise data. Developers can use it to translate natural language questions into accurate SQL queries powered by NVIDIA NIM, ensuring that every answer comes with verifiable provenance and execution steps. System Architecture The project is designed with a modern microservices architecture. It includes a Next.js frontend for the Web UI, a FastAPI Python backend for chat and catalog management, an ingestion worker for vector embeddings, and a PostgreSQL database equipped with pgvector to store both application data and the semantic ontology. Installation and Usage Getting started is straightforward using Docker Compose. You simply need to clone the repository, configure your environment variables including your NVIDIA API key in a .env file, and run Docker Compose to spin up the local stack. Once running, you can connect your databases and start asking questions through the built-in chat interface or integrate it with other tools via the MCP server.

What happens to AI if the US can't build data centers?

As multiple US states freeze data center approvals due to mounting electricity and infrastructure pressures, up to 41% of planned capacity faces cancellation risks. While existing massive clusters can still handle current model iterations, building the multi-gigawatt facilities needed for future frontier models by 2030 becomes nearly impossible. This shortage forces a dramatic shift: effective computing growth drops sharply, and labs must choose between training larger models or serving user queries under fixed power limits. This constraint could inadvertently narrow the technology gap for efficient model developers and open new windows for alternative players.

vercel-labs/agent-desktop: Computer use CLI for AI agents

Overview agent-desktop is a command-line interface and C library designed to give AI agents native computer-use capabilities. Instead of relying on brittle screenshots or pixel-matching techniques, it leverages official OS accessibility APIs to read desktop applications directly, presenting them as structured JSON trees. How It Works The tool inspects the target application and assigns a unique reference (ref) to every interactive UI element. The calling agent queries a snapshot, performs actions like clicking or typing using the ref, and checks the updated UI state in a continuous loop. By default, it operates headless, interacting with UI elements without needing to move the mouse pointer or steal active focus. Ecosystem and Integration agent-desktop natively supports macOS, Windows, and Linux by wrapping platform-specific accessibility APIs like AX API, UI Automation, and AT-SPI. It also includes an MCP (Model Context Protocol) server mode out of the box, allowing developers to easily expose all desktop commands as tools to any compatible AI assistant.

BotPsy: A Tiny 0.8B Personal Assistant Model That Beats Larger AI

BotPsy was developed by Tether AI Research to address the high costs, privacy risks, and operational vulnerabilities of relying exclusively on cloud-based frontier LLMs. By focusing on a sub-billion-parameter size, the model is optimized for efficient, secure on-device deployment. Training Methodology The model undergoes a four-stage post-training process. This begins with supervised fine-tuning on tool-use conversations, followed by multi-teacher on-policy distillation using specialized 4B teachers. It concludes with two rounds of reinforcement learning using rule-based and verification-driven rewards to master tool usage and general tasks. Performance and Efficiency Despite having only 0.8B parameters, BotPsy roughly doubles the agentic capability of its base model. It outperforms several larger models, including the 2.5× larger Qwen3.5-2B-Think, on multiple tool-use and multi-turn benchmarks while using fewer reasoning tokens.

Auditable Human-Agent Teams for Autonomous X-ray Experimentation

This preprint describes the use of coding-agent infrastructure grounded in validated scientific methods to perform autonomous synchrotron X-ray experiments on nanoparticle superlattices under evolving, human-defined objectives. By capturing complete human-agent and agent-agent transcripts, the authors audit decision provenance and characterize the division of cognitive labor. Across three experiments, 61-67% of messages involved interpretation or judgment, and the share of methodological and scientific contributions rose from 46% in the first experiment to 56-61% in later ones. Furthermore, 59-68% of error corrections involved multiple participants, and roughly half of all decisions incorporated input from another participant. While the work presents a notable integration of agentic systems with physical instruments, it is a preprint requiring further independent replication and code or hardware availability checks.

From Relevant Posts to Attributable Spans: Explicit Symptom Evidence for Depression Questionnaire Inference

Inferring standardized depression questionnaire responses from longitudinal social media histories often suffers from retrieval errors, such as picking up discussions about other people or multi-symptom posts that lack precise attribution. To address this, the authors propose SREE (Symptom Retrieval and Evidence-Grounded InfErence). SREE extracts first-person and symptom-specific text spans, selects a representative subset using a Facility Location-inspired objective, and performs Evidence-Gated Inference. Evaluated on BDI-Sen and eRisk 2019-2021 datasets, SREE achieves significant improvements in post-level precision and F1 compared to standard dense retrieval, while obtaining the highest exact item-level agreement across eRisk collections. This is a preprint paper, and while it improves evidence localization and attribution, the source does not detail independent replication or code release status.
