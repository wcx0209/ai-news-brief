Amazon Bedrock brings DeepEval and AutoEval to AgentCore for better AI agent testing

The Evaluation Challenge When deploying AI agents to production, simple metrics like latency or basic output checks aren't enough. An agent might resolve a customer support ticket while simultaneously leaking sensitive personal data. To fix this, Amazon Bedrock AgentCore Evaluations provides a structured way to measure what truly matters by mapping business goals to observable behaviors. A Catalog of Evaluators AgentCore brings together evaluators from three main sources. AWS built-ins cover response quality, task completion, and safety. Third-party managed options from DeepEval and AutoEval tackle complex multi-turn issues like knowledge retention, conversational completeness, and security flags. Developers can also create custom dimensions to grade multiple criteria in a single judge call. Flexible Running Modes To fit different development stages, AgentCore supports three execution modes using the exact same evaluator IDs. On-demand evaluation helps during quick debugging, online evaluation samples live production traffic, and batch evaluation runs regression tests against a golden dataset before any new release.

Designing for AI Agents: How Resend is Optimizing for Answer Engines and Autonomous APIs

The Rise of Agentic API Selection As coding agents become more autonomous, they increasingly make infrastructure decisions on behalf of developers—such as choosing which email provider to integrate. Zeno Rocha explores how tools like Claude Code recommend specific services and how these recommendations shift across model versions. This trend introduces answer engine optimization (AEO), requiring API providers to ensure their documentation, pricing, and capabilities are easily discoverable and parsable by non-human actors. Designing for Machine Consumers To support autonomous workflows, Resend has experimented with giving agents over 80 named Model Context Protocol (MCP) tools, enabling them to read pricing written in Markdown, register for services independently, and execute API calls. Rocha details the practical challenges of this paradigm, from handling DNS hurdles and Gmail throttling to rethinking traditional metrics like tracking pixels, which may no longer accurately measure human engagement when interacting through software agents.

Australia's PM faces a political storm over AI copyright and the creative sector

The Australian government is being courted by AI hyperscalers like Anthropic, which wants to base training models and renewable datacentres in the country, potentially creating a lucrative new green industry. However, this economic vision comes with a catch: tech companies are pushing the government to relax copyright laws that currently protect artistic work from being scraped without consent. Critics argue this would turn Australia into a global haven for data-washing. Beyond intellectual property, the rise of AI is triggering broader societal concerns, ranging from the automated mimicry of human art to the erosion of educational cognitive skills and mounting pressures on energy and water resources. The creative sector, traditionally a loyal political ally of the Labor party, is fiercely pushing back against what they see as a sell-out, demanding proper control, compensation, and the active promotion of human work.

How Workday Built Its Enterprise AI Agent Platform with LangGraph

Facing the demand to build and deploy production-ready AI agents by 2026, a small initial team of four at Workday set out to create an internal developer platform. Operating under strict enterprise security and data governance policies, they needed a solution that supported rapid prototyping and robust compliance. By leveraging LangGraph for agent orchestration and LangSmith for evaluation and observability, the team abstracted away underlying infrastructure. They developed a Python SDK dubbed 'Workday LangChain' to wrap primitives and connect with internal systems like LLM gateways and RAG services. This setup allowed them to out-of-the-box support advanced protocols like A2A and MCP. As a result, prototype delivery dropped from five months to under a day, enabling the team to scale up significantly and unify Workday's fragmented internal services into a single cohesive agent interface.

AMD Ships New EPYC 9006 Processors Built for Agentic AI

Background As AI shifts from simple chatbots to autonomous agentic workflows, data centers face massive concurrency demands. Multiple agents, tool calls, and subtasks require dense and efficient compute power. Key Details The new AMD EPYC 9006 SP7 is the first family member in a four-part rollout. It packs up to 256 cores and 512 threads per socket, reaches frequencies up to 5.3 GHz, and supports JEDEC-standard MRDIMM-12800 for up to 1.6 TB/s of memory bandwidth. It also introduces PCIe Gen 6 I/O to double bandwidth per lane. Industry Impact These processors are built to keep AI accelerators productive by moving large context windows quickly. Major cloud providers like Oracle and Microsoft are already integrating these chips into their cloud instances to support enterprise applications and agent orchestration.
