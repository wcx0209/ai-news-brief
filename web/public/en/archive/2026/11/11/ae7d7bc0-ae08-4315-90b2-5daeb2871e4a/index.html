v0.40.17 - AI Tooling and LLM Runtime Update with MLX and Vulkan Optimizations

This update brings exciting performance boosts and fixes for running AI models locally. It introduces concurrent generation support for Apple's MLX framework and leverages memory mapping for Vulkan integrated GPUs, making your local AI run smoother and faster. Plus, it improves the ChatGPT CLI experience with better restart handling.

Ollama Releases ↗Source published 2026-11-11 06:25 SGTOpen sourceArtificial Intelligence

Detailed Updates

This release focuses heavily on hardware acceleration and reliability for running large language models locally. Key improvements include support for concurrent generation on MLX, allowing for better multitasking when using Apple Silicon hardware. Additionally, developers have integrated memory mapping for Vulkan integrated GPUs, which significantly improves memory efficiency on supported devices. Core Fixes and Upgrades

Beyond hardware optimizations, the update includes a version bump for llama.cpp and related MLX components to stay aligned with the latest upstream capabilities. The ChatGPT CLI has also received a stability patch, ensuring graceful restarts and smoother session restoration during daily use.
