Amazon Bedrock brings DeepEval and AutoEval to AgentCore for better AI agent testing

AWS Machine LearningArtificial IntelligenceCompanySource published2026-11-11 06:35 SGT
Official releaseStage not established

According to AWS Machine Learning:

The Evaluation Challenge

When deploying AI agents to production, simple metrics like latency or basic output checks aren't enough. An agent might resolve a customer support ticket while simultaneously leaking sensitive personal data. To fix this, Amazon Bedrock AgentCore Evaluations provides a structured way to measure what truly matters by mapping business goals to observable behaviors.

A Catalog of Evaluators

AgentCore brings together evaluators from three main sources. AWS built-ins cover response quality, task completion, and safety. Third-party managed options from DeepEval and AutoEval tackle complex multi-turn issues like knowledge retention, conversational completeness, and security flags. Developers can also create custom dimensions to grade multiple criteria in a single judge call.

Flexible Running Modes

To fit different development stages, AgentCore supports three execution modes using the exact same evaluator IDs. On-demand evaluation helps during quick debugging, online evaluation samples live production traffic, and batch evaluation runs regression tests against a golden dataset before any new release.
