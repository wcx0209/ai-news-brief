langchain-fireworks 1.7.3 - Fix default max_tokens and refresh model profiles

Overview This release introduces version 1.7.3 of the langchain-fireworks package, focusing primarily on bug fixes and data maintenance to ensure smooth AI model interactions. Key Updates The update fixes a bug regarding the default max_tokens parameter by correctly pulling values from the defined model profiles. Additionally, it performs a routine refresh of the model profiles data to accommodate newly updated or adjusted AI models.
