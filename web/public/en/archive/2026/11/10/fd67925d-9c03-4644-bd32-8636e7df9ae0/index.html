Overview of Ripple Preview Ripple Preview is a massive 65B dense model developed by Ricursive Intelligence, designed from the ground up for agentic coding tasks. You can quickly fire it up using a simple command like ollama run ripple-preview, making it super convenient for developers looking to integrate advanced coding intelligence into their local workflows. Key Updates and Improvements This release introduces several exciting upgrades across different platforms. For Apple silicon users, the Qwen3.8 Flash Next now consumes about 27 GiB less memory, making it way more accessible on Mac hardware. Additionally, ollama launch claude now reliably routes Claude Code directly to your chosen model, and ollama launch will notify you if a cloud model has been retired. Other fixes include proper truncation handling in /v1/responses, returning an empty list instead of null in /v1/models, and adding CUDA 13.5 support for Windows on ARM, alongside an updated llama.cpp backend.
