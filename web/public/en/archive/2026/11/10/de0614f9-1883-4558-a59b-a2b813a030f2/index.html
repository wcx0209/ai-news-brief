How skills and agents work in AWS Quick

According to AWS Machine Learning: AWS Quick is an AI service that automates tasks and analyzes data using agents and reusable skills. It relies on natural language and connected data to streamline team workflows, letting users build and share custom skills easily.

AWS Machine Learning ↗Source published 2026-11-10 08:21 SGTOfficial releaseArtificial Intelligence

According to AWS Machine Learning:

Core Concepts AWS Quick places an AI agent at the center, which follows instructions, loads required skills, and interacts with connected data sources like knowledge bases and dashboards. By default, every user has access to Quick, but teams can also configure custom agents for specific tasks such as HR onboarding. Working with Skills A skill in AWS Quick is a reusable set of instructions based on an open standard, acting like a folder with a Markdown file and optional scripts. Quick uses system skills for common tasks like generating documents or browsing the web, while allowing users to create, publish and share their own custom skills. Best Practices Building production-ready skills requires engineering best practices. Creators must plan for potential failures, test every change, and avoid hardcoded values to ensure skills work seamlessly across different environments and team members.
