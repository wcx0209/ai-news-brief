NVIDIA Partners with Korean Giants to Boost Secure AI Agents

According to NVIDIA Generative AI: NVIDIA is teaming up with South Korean companies like Hyundai and LG AI Research to make AI agents safer and more useful for businesses. By using NVIDIA's new security tools and open datasets, Korean firms are building protected workspaces for artificial intelligence to handle sensitive tasks without risking data leaks.

NVIDIA Generative AI ↗Source published 2026-11-09 13:00 SGTOfficial releaseArtificial Intelligence

According to NVIDIA Generative AI:

As autonomous AI agents start handling more workplace tasks, keeping company data secure has become a major challenge. NVIDIA is addressing this by rolling out its Open Agent Safety Platform, which features a secure runtime called OpenShell. This tool uses isolated execution zones and strict rules to manage what AI agents can do.

In South Korea, major players are already jumping on board. Hyundai Motor Group is testing NVIDIA's new blueprints, while local security firm AIM Intelligence is combining its Starfort platform with OpenShell to block harmful instructions and data leaks. Meanwhile, LG AI Research is opening API access to its K-EXAONE-2.5 model, which was built using a massive dataset of 7 million synthetic Korean personas developed with NVIDIA. This collaboration helps ensure that AI tools are tailored to local contexts while keeping enterprise workflows secure.
