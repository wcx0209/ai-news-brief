Build memory-aware AI agents with Agentic Retrieve on Amazon Bedrock Managed Knowledge Base

According to AWS Machine Learning: Amazon Bedrock now integrates Managed Knowledge Base with AgentCore memory, enabling AI agents to remember past conversations and user facts automatically. By using AgenticRetrieveStream, applications can maintain private user memory and enforce strict document access controls without managing custom conversation databases.

AWS Machine Learning ↗Source published 2026-11-17 06:43 SGTOfficial releaseArtificial Intelligence

According to AWS Machine Learning: Building knowledge-grounded applications that truly remember users across sessions while strictly enforcing document access controls has traditionally required complex custom database logic. The integration of Amazon Bedrock Managed Knowledge Base with AgentCore memory simplifies this architecture. By passing user identity claims from an ID token, applications can leverage AgenticRetrieveStream to automatically restore short-term conversation history, extract long-term user facts, and query knowledge bases with document-level Access Control Lists (ACLs). This approach delegates session management, memory extraction, and access filtering entirely to the managed service, eliminating the need for a dedicated conversation history table while maintaining strict multi-tenant data isolation.
