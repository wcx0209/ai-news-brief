langchain-openai==1.8.0 - Dropping Python 3.10 Support and Adding OpenAIClassifier

This update officially stops supporting Python 3.10, requiring users to upgrade to Python 3.11 or newer. It also introduces the new OpenAIClassifier feature to help developers work with the Decisions API more easily.

LangChain Releases ↗Source published 2026-11-14 00:48 SGTOpen sourceArtificial Intelligence

Version Update Details

The langchain-openai maintainers announce the release of version 1.8.0, which includes several key updates for developers building applications with language models. The most notable change is that Python 3.10 support has been dropped because it reached its end-of-life, making Python 3.11 the new minimum requirement. Users staying on older Python environments will automatically stick with the 1.7.x branch. New Features and Improvements

Beyond environment adjustments, this release introduces the OpenAIClassifier designed for the Generally Available Decisions API. Additionally, the team refreshed internal model profile data to ensure better compatibility and performance with recent updates.
