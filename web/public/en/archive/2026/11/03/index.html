Harness-S: Training Smarter AI Agents Using Sibling Execution Systems

Background Training AI agents to handle complex coding and tool-use tasks usually relies on a fixed execution harness. However, every tweak to these scaffolds tends to fix some errors while breaking others, making it hard to find a universally superior setup. Details To solve this, researchers developed Harness-S. It builds a pool of specialized sibling harnesses along different repair directions. When the primary base harness fails completely on a task, the system routes the problem to these auxiliary harnesses to generate successful trajectories. An Adaptive Harness Router uses behavior profiles and LLM voting to select the best helper harness. The agent then learns from these rescued runs, effectively absorbing the helper behaviors into its own core policy. Impact Experiments across benchmarks like AppWorld, SWE-Gym, and DBBench show that the resulting policy greatly outperforms standard reinforcement learning methods when returning to the original base system. This proves that diverse execution environments can successfully transfer useful skills directly into the AI model itself.

EU launches call for proposals to build AI media platform

Background The European Union has officially opened a call for proposals focused on creating an AI-powered media platform. This project is designed specifically for European news and audiovisual media organizations. Details The goal is to develop a modular and multilingual infrastructure that serves the public interest. By leveraging this system, media outlets can overcome language barriers and streamline content sharing across borders within the European region. Impact This move represents a strategic effort by the EU to support its domestic media ecosystem through public infrastructure, ensuring that local news providers can harness the power of artificial intelligence while maintaining high standards of public service.
