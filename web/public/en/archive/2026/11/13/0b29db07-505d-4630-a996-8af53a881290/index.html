Historical brief · 2026-11-13

Release v5.23.0 - New Model Additions and Exporters Update

Hugging Face Transformers version 5.23.0 introduces a variety of new multi-modal and language models, including Inkling2, Liquid AI's LFM3, and InternLM3. It also overhauls the model exporters, allowing users to seamlessly export and run models on optimized runtimes like ONNX Runtime and OpenVINO with significant speed improvements.

Hugging Face Transformers Releases ↗Source published 2026-11-13 22:10 SGTOpen sourceArtificial Intelligence

New Model Additions

This release adds support for several prominent model families. Inkling2 is a multi-modal model supporting text and image inputs with a large parameter scale. Liquid AI's LFM3 and LFM3-VL introduce hybrid architectures combining gated short convolutions and grouped-query attention. Other notable additions include IQuestCoder for code generation, Shanghai AI Laboratory's InternLM3 instruction-tuned model, and experimental decision heads like JEV. Exporters and Backend Runtimes

The update brings a major overhaul to model exports. Every export now returns an ExportedModel, which shares the same API as the original model and can be pushed to the Hub and reloaded. It supports Dynamo, ONNX Runtime, OpenVINO, and ExecuTorch, with built-in runtime fusions that make decoding significantly faster than standard PyTorch eager execution. Core Bugfixes and Optimizations

Beyond new models, version 5.23.0 addresses a wide range of issues across vision pipelines, distributed training, attention mechanisms, caching, and audio processing. These include fixing cache correctness in various models, optimizing expert parallelism, and improving overall stability for multi-GPU setups.
