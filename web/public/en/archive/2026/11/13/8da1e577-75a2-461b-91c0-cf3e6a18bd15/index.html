Gamer: A Generalist Vision-Language-Action Foundation Model for Long-Horizon Real-Time Game Agents

Researchers from miHoYo introduce Gamer, a vision-language-action foundation model designed for long-horizon, real-time game interaction via standard screen pixels, keyboard, and mouse inputs.

Hugging Face Daily Papers ↗Source published 2026-11-13 03:00 SGTMedia reportArtificial Intelligence

The miHoYo Honkai AI R&D team presents Gamer, a generalist Vision-Language-Action (VLA) foundation model designed to interact with complex 3D games through standard human interfaces—screenshots, keyboard, and mouse—without relying on privileged game states or custom APIs. The authors report a complete pipeline encompassing continual pre-training on over 10,000 hours of gameplay trajectories, supervised fine-tuning using an automated annotation pipeline yielding approximately 1.2 million reasoning and 223,000 memory annotations, and an optimized inference engine called Streaming-vLLM that achieves over 20 times lower inference latency. To handle long-horizon tasks, the team implements Temporal-Aware GRPO (TA-GRPO) for reinforcement learning over hour-long trajectories. In automated evaluations across main storylines in Honkai: Star Rail, the authors report that Gamer handles over 95% of challenges. The work provides insights into scaling laws for game intelligence and the interplay between inference speed and online reinforcement learning effectiveness. As this is a preprint, independent replication, code availability details, and comprehensive generalization baselines beyond the developers' proprietary test environments remain to be fully established.
