Tenstorrent tt-metal v0.83.0: Hardware Acceleration & AI Model Updates

Overview and Low-Level Kernels The v0.83.0 release brings crucial updates to low-level kernels (LLK), including full tile shape support in unpack tilize and various SFPU enhancements for Wormhole hardware. These changes improve raw computing efficiency and error recovery when tests are interrupted. Metalium and TT-NN Core Updates Core Metalium and TT-NN libraries received multiple stability fixes and performance tweaks. MeshBuffer now returns built device buffers without relying on the lazy-build lock, and several tensor operation defects—such as DiT norm and RoPE bugs—have been ironed out. Model Support and Infrastructure Model support sees exciting expansions, adding optimizations for Ideogram 4, Kimi-K3, and MiniMax-H3. Infrastructure improvements also streamlined CI workflows and memory management, utilizing custom ephemeral allocations via SRAMArena.
