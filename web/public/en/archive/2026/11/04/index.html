Confucius4-R2T2: A Stable-Prefix Streaming ASR Model for Real Real-Time Transcription

This paper presents Confucius4-R2T2, a stable-prefix streaming automatic speech recognition (ASR) model designed for real-time applications such as voice agents and simultaneous translators. Traditional streaming ASR systems often revise partial transcripts as more context arrives, which wastes compute and causes errors in downstream agents. To solve this, the authors introduce the Longest Stable Prefix (LSP) concept, proving it to be monotone, consistent with full-audio outputs, and maximal. By post-training Qwen3-ASR-1.7B on 1,500 hours of Chinese and English audio using LSP supervision while freezing the audio encoder and projector, R2T2 produces append-only, stable text without architectural modifications. Extensive evaluations demonstrate that R2T2 approaches base-model full-context quality with low emission lag and strong cross-lingual generalization. The code and model weights are open-sourced.

Cohere Embed 5 and Rerank 5 Are Now Live on OpenRouter

How It Works Building a modern RAG pipeline usually requires juggling multiple tools, but OpenRouter now hosts both of Cohere's latest retrieval powerhouses under one roof. The setup uses Embed 5 Pro to build a searchable document index at the highest quality, while Embed 5 Fast handles real-time queries with minimal latency, leveraging a shared embedding space to preserve retrieval accuracy. Precision Reranking After fetching initial candidates via vector similarity, Rerank 5 steps in to score and filter the results. Because its relevance scores are fully calibrated across different queries and domains, developers can rely on a single threshold to cleanly strip out weak context before it ever reaches the language model. Practical Benefits This unified approach simplifies development and cuts down on infrastructure overhead. Every component, from vector generation to the final chat response, runs through the same API, making it simple to swap models or scale up with enterprise documents.
