LangSmith Launches Tool Gateway for Secure Agent Actions

According to LangChain Blog: LangSmith has launched Tool Gateway in public beta to help engineering teams securely manage agent tool calls. According to the company, the new managed layer handles credentials and identity, allowing agents to run with user permissions or service accounts while logging every action for compliance and debugging.

LangChain Blog ↗Source published 2026-11-20 02:00 SGTOfficial releaseArtificial Intelligence

According to LangChain Blog:

Background and Challenges

As AI agents move beyond simple chat windows to run autonomously on schedules or in the background, they require access to external tools and systems. According to LangSmith, managing identities, access tokens, and security for hundreds of tools across multiple users creates a massive engineering burden and introduces security risks when handled manually.

Core Features

Tool Gateway acts as a single managed layer routing tool requests through a unified URL. It manages identity resolution, mapping tool calls to either the individual user's credentials or dedicated agent profiles. Additionally, it offers policy controls such as deny rules and human-in-the-loop approvals for sensitive actions, alongside built-in servers for common apps like Google and GitHub to eliminate custom OAuth setups.

Impact and Visibility

Every tool call is recorded within agent traces, logging the specific tool, server, user, latency, and outcome without storing sensitive payload data. Enterprise plans also include centralized audit logs, giving security teams a clear, unified record to answer compliance questions and debug production issues faster.
