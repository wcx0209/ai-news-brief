How to make open-source AI models run fast for long coding tasks

According to Ollama Blog: Together AI and Ollama explain why coding agents slow down over long sessions and how to fix it. Because agents send the entire conversation history with every step, the GPU has to re-read thousands of tokens unless you protect the prefix cache.

Ollama Blog ↗Source published 2026-11-16 08:00 SGTOfficial releaseArtificial Intelligence

According to Ollama Blog:

Coding agents have a unique traffic pattern involving a large input sequence length and a small output sequence length. As a session progresses through dozens or hundreds of turns, the input grows massively while the output remains a short tool call. Without proper optimization, the GPU re-reads the entire history on every turn, causing performance to degrade quadratically.

To solve this, developers must rely on prefix caching, which saves intermediate key-value pairs so the engine only processes new content. However, the cache breaks easily. Ollama's harness side highlights that putting changing elements like timestamps in the system prompt, altering reasoning effort mid-session, or injecting tool definitions near the top will instantly destroy the cache. Meanwhile, Together AI's inference engine side explains the challenges of keeping the cache alive, including smart request routing to the correct data center node, offloading idle session memory to the CPU, and splitting prefill and decode phases across clusters.
