Historical brief · 2026-11-18

Materialise and Additive Industries launch new metal 3D printing software, cutting preprocessing time by 87%

Materialise and Additive Industries report a new Build Processor that cuts metal 3D printing file preparation time down to 6 minutes. According to the companies, this upgrade uses multi-process parallel computing to reduce device wait times and improve manufacturing efficiency for complex parts.

Background and Efficiency Gains

Materialise and Additive Industries report that their newly developed Build Processor significantly improves computational efficiency for metal additive manufacturing. According to benchmark tests provided by the companies, processing a standard task that previously took about 46 minutes with the Classic Build Processor 2.6 now requires only 6 minutes, marking a reduction of approximately 87%. The companies state this acceleration stems from multi-process parallel computing and algorithm optimization, which helps minimize equipment wait times during the preparation of large and complex models.

Advanced Features and Ecosystem Integration

The new software extends several advanced control features previously limited to the MetalFab 420K platform, such as optimized multi-laser load balancing, vector-based spot size adjustment, and Ghost Vector technology for improved thermal stability. Furthermore, the software maintains integration with Materialise Magics and the CO-AM manufacturing platform, allowing existing MetalFab users to migrate their profiles without rebuilding parameter systems.
