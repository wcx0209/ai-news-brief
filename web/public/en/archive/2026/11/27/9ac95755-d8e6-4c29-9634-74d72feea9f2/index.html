Historical brief · 2026-11-27

v0.84.0-dev20261127: Tenstorrent TT-Metal Updates for Low-Level Kernels and AI Models

This development release from Tenstorrent brings comprehensive updates to the tt-metal ecosystem, focusing on low-level kernel improvements, model execution enhancements, and CI/infrastructure optimizations. Key changes include performance boosts for models like GLM-5.3, expanded hardware support for Quasar, and various bug fixes across device compilation and runtime stacks.

Tenstorrent TT-Metal Releases ↗Source published 2026-11-27 09:46 SGTOpen sourceArtificial Intelligence

Low-Level Kernels (LLK)

The update introduces various improvements to low-level kernels, including fixes for matrix multiplication hangs on tiny tiles and performance enhancements for SFPU operations on Quasar and Wormhole architectures. New performance tests for MoE gates, logit softcaps, and fast-tilize operations have also been added.

Metalium Core & TT-NN

Core execution components receive updates such as improved host allocation of sharded buffers, inter-domain routing for fabrics, and DRAM profiler backend enhancements. TT-NN library updates focus on accuracy sweeps for binary INT32, sparse ring attention optimizations, and group normalization refinements.

Training and Models

The tt-train component adds asynchronous rollout support for GRPO, distributed checkpointing formats, and deep optimization for DeepSeek and GLM-5.3 models. Model execution pathways are refined for better performance on multi-chip hardware configurations like Blackhole Galaxy.
