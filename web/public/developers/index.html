03 / DISCOVERY

How does AI
know this exists?

1

Crawlers can find it

The developer page, sitemap, llms.txt, structured article data and visible site links make the interfaces discoverable and citable.

2

Agents still need a connection

Most AI assistants do not automatically execute arbitrary APIs they discover on the web. A user, workspace admin or agent developer must add the MCP endpoint or OpenAPI spec.

3

Distribution makes it native

Publishing the connector in product directories or the MCP registry can make installation easier. Discovery does not grant permission: all tools remain read-only.
